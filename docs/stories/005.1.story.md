## Description
Como calouro de Sociologia da UFCG vindo do Sertão Paraibano, quero acessar uma página que explique a proposta do curso em linguagem direta, para que eu me cadastre e tenha acesso aos materiais do Dashboard AIOX v2.0.

## Acceptance Criteria
- [ ] Dado que o usuário acessa `landing.html`, quando a página carrega, então o conteúdo aparece em menos de 3s em conexão 3G
- [ ] Dado que o usuário preenche o formulário, quando informa e-mail sem `@ufcg.edu.br`, então vê mensagem de erro antes de enviar
- [ ] Dado que o usuário preenche nome e e-mail válidos, quando clica em "ENTRAR NA FÁBRICA", então o lead é inserido na tabela `leads` do Supabase
- [ ] Dado que o e-mail já está cadastrado, quando tenta cadastrar novamente, então vê mensagem amigável sem quebrar a página
- [ ] Dado que o cadastro é bem-sucedido, quando a inserção é confirmada, então o botão exibe "CADASTRO REALIZADO ✓"
- [ ] Dado qualquer dispositivo, quando acessa a página, então o layout é responsivo em 375px e 1280px

## Scope
**IN:**
- `landing.html` — página estática completa
- Formulário com validação client-side (`@ufcg.edu.br` / `@estudante.ufcg.edu.br`)
- Integração Supabase JS (anon key, RLS)
- Estados do botão: padrão → loading → sucesso / erro
- Estética glassmorphism alinhada ao widget AIOX em `index.html`

**OUT:**
- Autenticação de usuários
- Painel administrativo de leads
- Integração com e-mail marketing
- Analytics
- Backend próprio
