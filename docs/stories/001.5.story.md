# Story 001.5: Quiz sobre Globalização

**Status:** Done

**Agent:** @dev (Dex)
**Created:** 2026-04-07

## Description
Implementar uma seção interativa de Quiz sobre Globalização na página `index.html`, permitindo ao estudante testar seus conhecimentos sobre os conceitos de Octavio Ianni e globalização abordados na aula de Sociologia do Cohort 8.

## Acceptance Criteria
- [ ] Seção "Quiz: Globalização" visível na página abaixo de "Minhas Anotações"
- [ ] Mínimo de 5 perguntas de múltipla escolha sobre globalização e Ianni
- [ ] Feedback imediato por resposta (certo/errado + explicação)
- [ ] Pontuação final exibida ao concluir o quiz
- [ ] Botão "Reiniciar" para refazer o quiz
- [ ] Resultado salvo no LocalStorage (chave: `ianni-quiz-score`)

## Scope
**IN:**
- Seção de quiz no index.html (HTML + JS puro)
- Perguntas sobre globalização, mundialização do capital, Estado-nação e obras de Ianni
- Feedback por questão e pontuação final
- Persistência do último resultado via LocalStorage

**OUT:**
- Backend ou banco de dados
- Sistema de ranking ou múltiplos usuários
- Geração dinâmica de perguntas via IA
- Frameworks JS externos (React, Vue, etc.)

## Dependencies
- **Stories:** 001.1 (estrutura base HTML), 001.3 (LocalStorage já implementado)
- **Resources:** Nenhum externo

## Complexity Estimate
M — 3 pts (lógica de quiz, estado JS, integração com LocalStorage existente)

## Business Value
Permite ao estudante fixar os conceitos de globalização de forma ativa e autotestável, reforçando o aprendizado da aula de Sociologia.

## Risks
- Perguntas precisam ser academicamente corretas (risco: imprecisão conceitual)
- Layout pode ficar poluído se mal integrado ao design existente
