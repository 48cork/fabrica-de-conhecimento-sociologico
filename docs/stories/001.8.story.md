# Story 001.8: Conto Filosófico — Capitalismo 4.0 (Cavalo de Troia)

**Status:** InReview
**Epic:** 001
**Agent:** @dev (Dex)
**Created:** 2026-04-07
**Complexity:** L

## Description
Criar uma nova seção "Conto: O Crime do Silêncio" no `index.html` que apresente um conto
filosófico de 5 páginas para alunos universitários, usando a estratégia narrativa de "Cavalo
de Troia": ficção como veículo de crítica filosófica sobre o Capitalismo 4.0, dramatizando
os conceitos de Ghiraldelli (Tecnopolítica, fim do descanso 24/7, excesso de informação,
dinheiro como único Deus) e a transição da burguesia enraizada de Ianni para a plataforma digital.

## Acceptance Criteria
- [ ] Nova seção "Conto: O Crime do Silêncio" visível na página, após "A Transição: Do Mundial ao Digital"
- [ ] Conto estruturado em 3 atos conforme definição do usuário:
  - [ ] **Ato 1 — O Despertar do Pixel:** ritual de telas, consciência colonizada pela notificação
  - [ ] **Ato 2 — A Cidade Sem Sombras:** poder algorítmico invisível, arquitetura do controle
  - [ ] **Ato 3 — O Crime do Silêncio:** descanso como heresia, silêncio como transgressão
- [ ] Conceitos filosóficos embutidos na narrativa (não explicitados como teoria): Tecnopolítica, 24/7, excesso de informação, dinheiro como único Deus
- [ ] Nota de rodapé ou seção "Chaves de Leitura" ao final ligando ficção → conceitos teóricos
- [ ] Layout distinto do restante da página (tipografia narrativa, separação visual dos atos)
- [ ] Rastreável ao research: `docs/research/capitalismo-4.0/notas-ghiraldelli.md`

## Scope
**IN:**
- Conto em prosa (~5 páginas / ~2500 palavras) em português
- 3 atos com separação visual clara
- Seção "Chaves de Leitura" mapeando ficção → teoria
- Estilização narrativa com Tailwind (diferente das seções analíticas)

**OUT:**
- Interatividade (clique para revelar, animações)
- Versão PDF ou exportação
- Múltiplos personagens com nome próprio (foco no arquetipo)

## Dependencies
- **Stories:** 001.6 (Análise Crítica — base conceitual), 001.7 (Ghiraldelli — conceitos já estabelecidos)
- **Research:** `docs/research/capitalismo-4.0/notas-ghiraldelli.md`

## Complexity Estimate
L — 5 pts (produção de conteúdo narrativo extenso + layout diferenciado + chaves de leitura)

## Business Value
Transforma a página de estudo em material pedagógico de alto impacto: o conto permite que alunos
universitários absorvam crítica filosófica via ficção — estratégia "Cavalo de Troia" que torna
conceitos áridos de Ghiraldelli e Ianni acessíveis e memoráveis.

## Risks
- Risco de didatismo excessivo: o conto deve mostrar, não explicar — teoria embutida, não exposta
- Risco de extensão: manter equilíbrio entre profundidade e leiturabilidade (~2500 palavras)
- Risco de desconexão: "Chaves de Leitura" devem fazer a ponte sem destruir a experiência narrativa
