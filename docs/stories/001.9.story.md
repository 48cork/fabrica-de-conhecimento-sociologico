## Description
Adicionar uma seção interativa de "Questões Provocativas" ao `index.html` usando o padrão
acordeão (accordion): perguntas filosóficas que, ao serem clicadas, revelam uma reflexão
aprofundada conectando Ianni, Ghiraldelli e o Capitalismo 4.0. Objetivo: estimular o
pensamento crítico do estudante antes das provas e seminários.

## Acceptance Criteria
- [ ] Seção "Questões Provocativas" após o conto "O Crime do Silêncio"
- [ ] Mínimo de 5 perguntas em formato acordeão (clique para expandir/recolher)
- [ ] Cada questão conecta ao menos um conceito do material (Ianni ou Ghiraldelli)
- [ ] Apenas uma questão aberta por vez (fecha a anterior ao abrir nova)
- [ ] Animação suave de abertura/fechamento
- [ ] JS vanilla — sem frameworks externos
- [ ] Layout consistente com a identidade visual da página

## Scope
**IN:** Seção acordeão estática com JS vanilla
**OUT:** Backend, banco de respostas do usuário, sistema de avaliação
